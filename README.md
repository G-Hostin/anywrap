# Anywrap

Drop a personal data export (a running log, a bank CSV, a watch history, a sleep diary from any app) and flip through a year-in-review story. The AI picks the story; your browser computes every number, and each number comes with a receipt.

Built for [Build With AI: Basics](https://learn-ai-basics.devpost.com/) (Devpost) with the [Devpost Learn skill pack](https://github.com/challengepost/learn-ai-basics). The planning documents are in [`devpost/`](devpost/): [scope](devpost/scope.md), [PRD](devpost/prd.md), [spec](devpost/spec.md) and the [build checklist](devpost/checklist.md).

## How it works

1. **Your browser reads the file** (CSV, TSV, JSON or JSON Lines, up to 50 MB) and writes a short summary: column names, detected types, ranges, a few example values and 5 example rows. The file itself never leaves the browser.
2. **The AI picks the story.** Gemini receives only the summary (2 to 7 KB for the sample files, one of which is 1.1 MB). It works out what the file is, then returns a plan: which rows to leave out, and 6 to 8 calculations chosen from a fixed menu (total, average, record, top, timeline, busiest day, streak, share, comparison…). The API enforces the plan's format with a JSON schema.
3. **Your browser computes every number** by running that plan on every row. If a calculation fails, for example on a wrong column name, the errors go back to the AI once for a corrected plan.
4. **The AI writes the captions** from the computed results only. A checker compares every number in every caption with the results of that card. Numbers written in words ("twelve") and arithmetic words ("twice") are rejected too. A rejected draft is rewritten once; anything that still fails gets a plain caption built from the results.
5. **Every card has a receipt** on its back: the calculation in words, the columns, the period, the rows removed by each exclusion, the rows used, and the table behind the chart. "What the AI saw" shows the exact text sent to the AI, next to the size of your file.

Why not let the AI read the file, or write code to analyze it? Because then you can't tell where a number came from. Here, every number traces back to one named calculation on your rows.

## Run it

Requirements: Node.js 24 or later, and a free [Gemini API key](https://aistudio.google.com/apikey) (no billing needed).

```sh
npm install
cp .env.example .env        # then put your key after GEMINI_API_KEY=
npm run build
npm start                   # http://localhost:5173
```

For development with hot reload: `npm run dev`.

The local server keeps the key out of the browser. It only forwards small JSON bodies (64 KB at most) to the Gemini API, with fixed prompts. The model defaults to `gemini-3.5-flash-lite`, which runs on the free tier; set `GEMINI_MODEL` in `.env` to use another one. On the free tier, Google may use the requests (the summary and the computed results, never the file) to improve its models.

Five sample exports are included in [`public/samples/`](public/samples/). They are generated by `npm run samples` with a fixed seed. **All the data in them is made up**: fictional merchants, channels and gear, and public-domain book titles. The formats imitate real exports (a Strava-style activity CSV, a Goodreads-style library export, a US bank CSV, a Google Takeout-style watch history, and a sleep diary from an unknown app with French headers, semicolons and decimal commas).

## Checks

```sh
npm test            # engine vs numbers recomputed independently on all 5 samples, number checker cases
npm run typecheck
npm run check:live  # full pipeline on every sample against the real API (10 requests on your free quota)
```

## Project layout

```
server/            local server: API key, fixed prompts and JSON schemas, Gemini calls
src/engine/        file reader, summary, plan runner, formatting, number checker (no dependencies)
src/pipeline.ts    file → summary → plan → computed results → checked captions → story
src/ui/            home, working screen, story player, cards, charts, receipts, "What the AI saw", share image
scripts/           sample generator, live check
tests/             node:test suites
devpost/           planning documents from the skill pack
```

## Limits

- One file at a time. A whole Google Takeout archive has to be unzipped first, and you pick one file from it.
- Captions are in English, whatever the file's language.
- The AI chooses the period, usually the latest calendar year with good coverage.
- Comparisons between groups show a difference, not a cause. Their receipts say so.
